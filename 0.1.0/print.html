complexity

The cognitive and cyclomatic complexity of Pepper functions, scored on the syntax tree the Pepper compiler's own parser builds. The pep-complexity command-line tool (main.pep) is built on it.

Bring it in with import complexity.

  • score_source: scores every function in one source file
  • FunctionScore: one function's name, line and scores

Example

import complexity;

main(): int {
    var scores = complexity.score_source("f(x: int): int {\n    return x > 0 ? 1 : 0;\n}\n");
    print(scores.value()[0].cognitive);   # 1
    return 0;
}

FunctionScore

One function's scores.

Fields

The function's name; a member is Type.name, a constructor Type.construct, a destructor Type.destruct, and a property's accessor Type.property.get or .set.

line

The line of its name, from 1.

Its cognitive complexity: 0 for straight-line code.

Its cyclomatic complexity: 1 for straight-line code.

score_source

score_source(source: String): Result<FunctionScore[]>

Scores every function with a body in source, in source order: free functions, and the methods, constructors, destructors and property accessors of structs, enums, traits and extensions. A closure counts toward the function it is written in.

Parse on a big stack (compiler.parse.on_compiler_stack) to take deeply nested source.

Parameters

  • source — the text of one source file

Returns

  • the scores, or the first syntax error as line:column: error: message

Example

var scores = complexity.score_source("f(x: int): int {\n    if (x > 0) {\n        return 1;\n    }\n    return 0;\n}\n");
# scores.value()[0]: name "f", line 1, cognitive 1, cyclomatic 2
